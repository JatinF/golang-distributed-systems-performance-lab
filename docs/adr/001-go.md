# ADR 001: Go for the lab

## Status

Accepted for this repository.

## Context

The lab exists to show concurrency, backpressure, and measured throughput. The work is goroutines, channels, a bounded pool, and profiles of CPU, heap, allocations, and goroutines.

## Decision

The module is Go 1.26.4. The worker pool is the standard library: goroutines, a buffered channel, a mutex, and a condition variable. Context cancellation is the deadline and shutdown signal.

## Consequences

`go test -race` is the concurrency check. pprof is the profile format. A language runtime with a different concurrency model is out of scope for this repository.
